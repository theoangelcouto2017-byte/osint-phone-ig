# 🔍 OSINT Phone & Instagram — Termux

Herramienta OSINT para obtener **IP aproximada**, **geolocalización (país/ciudad)**
y datos públicos a partir de:

- 📞 Un número de teléfono
- 📸 Un usuario de Instagram
- 🌐 Una IP directa

> ⚠️ Sin API keys. Todo con servicios públicos gratuitos.
> La geolocalización es **aproximada** (nivel ciudad/proveedor), no GPS exacto.

## 🚀 Instalación

```bash
git clone https://github.com/TU_USUARIO/osint-phone-ig.git
cd osint-phone-ig
chmod +x *.sh modules/*.sh
bash install.sh
bash menu.sh
